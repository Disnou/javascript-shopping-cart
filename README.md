 📖 Sobre o Projeto
Este projeto simula a interface de uma loja online. O foco principal foi a aplicação de lógica de iteração (loops) e manipulação de múltiplos IDs dinâmicos*para criar uma experiência de usuário fluida. O projeto utiliza Bootstrap 5 para garantir um layout limpo e responsivo.

 🧠 Conceitos Práticos Abordados
1. Lógica Dinâmica de IDs: Uso de concatenação de strings para acessar elementos específicos (ex: `'quantidade_' + produto`).
2. Cálculos em Tempo Real: Funções que calculam o valor total de cada item e o subtotal da compra instantaneamente ao clicar nos botões de adição ou subtração.
3. Estilização com Bootstrap e CSS:Uso de tabelas, badges e ícones do Bootstrap combinados com CSS personalizado para criar uma identidade visual única (como o cifrão colorido e as bordas personalizadas).
4. Validação de Quantidade: Garantia de que a quantidade de produtos nunca seja negativa.

 🛠️ Como Executar
1. Mantenha a estrutura de pastas: `index.html`, `style.css` e uma pasta `js/funcoes.js`.
2. Certifique-se de ter conexão com a internet para carregar o Bootstrap via CDN.
3. Abra o `index.html` no seu navegador.

 📖 About the Project
This project simulates an online store interface. The main focus was applying iteration logic (loops) and dynamic ID manipulation to create a seamless user experience. It uses Bootstrap 5 to ensure a clean and responsive layout.

 🧠 Practical Concepts Covered
1. Dynamic ID Logic:Using string concatenation to access specific elements (e.g., `'quantidade_' + produto`).
2. Real-Time Calculations: Functions that calculate individual item totals and the overall subtotal instantly upon clicking add or subtract buttons.
3. Bootstrap and CSS Styling: Utilizing Bootstrap tables, badges, and icons combined with custom CSS to create a unique visual identity.
4. Quantity Validation: Ensuring product quantities never drop below zero.
